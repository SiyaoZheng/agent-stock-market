Agent Stock Market — OpenAI Agents SDK

START
  Run python3 app.py, or double-click run.command on macOS.
  Open http://127.0.0.1:8873/ in a browser.
  Install: python3 -m pip install --break-system-packages -r requirements.txt
  A DeepSeek key can come from .env, the model connection dialog, or global llm credentials.
  The model is deepseek-flash with thinking={"type":"disabled"} on every request.

MARKET
  Qinghe Technology (QH) starts at 100; Yuanshan Energy (YS) starts at 50.
  Eight agents and Adrian each start with 100000 simulated credits, 200 QH and 400 YS shares.
  A separate Opening liquidity account provides a finite set of opening orders.
  Executed trades update prices. Quantities are shares and the price tick is 0.01 credits.

ORDERS
  Limit buys execute at the limit or lower; limit sells at the limit or higher.
  Better prices match first. Orders at the same price match in arrival order.
  The resting order sets the execution price. Partial fills are supported.
  Unfilled limit quantities remain open. Unfilled market quantities are cancelled immediately.
  Open buys reserve cash; open sells reserve shares. Cancellation releases the remainder.
  Each order accepts 1–10000 whole shares. Overdrafts, short sales and self-trades are prevented.
  The market has no fees, leverage, corporate actions or trading-hours restrictions.

CHARTS AND ACCOUNT COMPARISON
  The price chart uses actual trade times, beginning with the initial quote.
  Each trade shows the buyer, seller, initiating trader, quantity and change from the last price.
  Complete trade history survives server restarts.
  The comparison includes eight agents and Adrian; the opening account is marked as a system account.
  Equity = total cash + holdings valued at the latest execution price, including reserved assets.
  Profit/loss = equity - initial equity, including unrealized changes in holdings.
  Return = profit/loss / initial equity. Each participant starts with equity of 140000 credits.

TRADING AGENTS
  Agents independently read chat, quotes, their own accounts and open orders before acting.
  Trading tools: get_market_snapshot, get_account, place_order, cancel_order.
  Orders and cancellations change the local exchange and post receipts in chat.
  The group has no total round limit. Agents may chat, @mention, vote or join sign-up chains.
  Choose a calm, natural or lively pace, or pause the agents.
  A server restart preserves the requested run state; a paused market stays paused.

SOCIALDATAX SEARCH
  search_social_media(platform, query, limit) searches public industry information.
  Channels: Weibo, Xiaohongshu, Douyin, Kuaishou, Bilibili, Zhihu, WeChat Channels,
  Toutiao, Baidu Tieba, X/Twitter, YouTube, Instagram and TikTok.
  A request returns 1–10 results (default 5), including text excerpts, authors, dates,
  engagement metrics and original source URLs when supplied by the platform.
  Agents search on first receiving the tool, then when they need new information.
  Results enter only that agent's context and the observer's search view.
  share_search_result posts a selected result and short comment to the group.
  Source URLs are preserved in full. Only executed orders change simulated stock prices.
  Set SOCIALDATAX_API_KEY, or reuse existing local Codex authorization for the same MCP endpoints.
  Requests go directly to the official SocialDataX MCP services and use account credits.
  Search is read-only; the application does not post to social media accounts or send direct messages.

INDIVIDUAL CONTROLS
  Select a trader to view state summaries, intentions, mood, history, account and persona.
  Edit personas, personal rules and private memories live. Shared topics and rules are also editable.
  State summaries are short reports produced by the agent; model thinking remains disabled.
  The saved version (epoch) and loaded version (loaded_epoch) are shown separately.
  loaded_epoch and loaded_at update after the model uses the new instructions and calls read_group.
  Editing one trader cancels that trader's pending generation; other agents and open orders continue.
  Private rules and memories are not sent directly to other agents through market or chat tools.

PERSISTENCE
  .runtime/state.json stores chat, private state, accounts, orders, trades, searches and run state.
  The interface can export JSON. Server restarts preserve the market.
  Explicitly creating or clearing a scenario resets the market and chat.

FILES
  app.py: API server, agent loops, private state and tools.
  market.py: Central matching engine with integer-cent accounting.
  social_search.py: Multi-platform SocialDataX search and normalized results.
  personas.json: Initial trader backgrounds and preferences.
  static/: Chat, observer controls, trading, charts and search views.
