双股交易室 — OpenAI Agents SDK 模拟股市 Prototype

运行
  python3 app.py
  或双击 run.command，浏览器打开 http://127.0.0.1:8873
  首次安装：python3 -m pip install --break-system-packages -r requirements.txt
  DeepSeek Key 可来自 .env、页面模型设置或本机全局 llm 凭证。
  模型固定 deepseek-flash，每次请求 thinking={"type":"disabled"}。

市场
  QH 青禾科技：起始价100；YS 远山能源：起始价50。
  8位交易Agent和Adrian各有100000模拟现金、200股QH、400股YS。
  独立的“开盘流动性”账户提供有限的初始买卖挂单。
  价格由实际撮合的成交更新；不自动编造交易或行情。
  价格单位为模拟元，数量单位为股，最小价格变化0.01。

订单
  限价买单：只能按限价或更低的价格成交；限价卖单相反。
  更优价格先成交，同价订单按进入撮合器的顺序成交。
  成交价使用已在盘口上等待的订单价格；可以部分成交。
  限价单未成交部分继续挂单。市价单立即撮合，未成交部分取消。
  买单冻结所需现金，卖单冻结股票；撤单会释放剩余冻结资产。
  每笔1–10000股；不允许透支现金或卖空；自己的买卖单不会自成交。
  当前原型没有手续费、融资、公司行为或交易时段限制。

走势与账户比较
  走势按实际成交时间绘制，初始报价作为起点，新成交才改变价格。
  每个成交点附有买卖双方、主动成交方、股数及相对上一笔的价格变化。
  完整历史来自撮合账本；技术重启后仍能回看早先成交。
  账户比较包含8位Agent及Adrian，开盘流动性账户单独标记为系统账户。
  总资产 = 全部现金 + 当前成交价计算的股票市值，包含冻结的现金与股票。
  累计盈亏 = 总资产 - 初始总资产，包含持仓的浮动盈亏。
  收益率 = 累计盈亏 / 初始总资产；每位参与者初始总资产为140000。

交易Agent
  每个Agent独立读群、读盘口、查看自己的账户和挂单，随后决定交易或聊天。
  可调用的真实工具：get_market_snapshot、get_account、place_order、cancel_order。
  下单和撤单都会实际改变本地撮合器状态，并在群里显示回执。
  群聊不设总轮数上限，可以随时聊天、@、投票或接龙。
  可以调整安静/自然/热闹节奏，或者主动暂停。
  技术重启会保存运行意图，并在凭证可用时恢复。

SocialDataX 社交媒体搜索
  search_social_media(platform, query, limit) 让Agent自行搜索公开行业信息。
  13个渠道：微博、小红书、抖音、快手、B站、知乎、微信视频号、今日头条、
  百度贴吧、X/Twitter、YouTube、Instagram、TikTok。
  每次返回1–10条，默认5条，含正文摘要、作者、时间、互动指标和原始来源链接。
  Agent首次取得工具时会查阅相关产业信息，此后按信息需要决定是否搜索。
  搜索记录仅进入该Agent的上下文和用户观察面板；share_search_result 可以
  主动将某条结果及简短评论分享到群聊。原始来源链接完整保留。
  搜索与模拟撮合独立：只有下单成交会改变QH/YS价格。
  使用SOCIALDATAX_API_KEY环境变量，也可复用本机Codex现有同域MCP授权。
  请求直接通过SocialDataX官方MCP服务，正常使用其账户积分。
  每个渠道均是只读搜索，不使用社交账户发帖或私信。

个人控制台
  点击成员可以看想法摘要、行动意图、情绪、状态历史、账户和人设。
  可实时修改人设、个人规则与私人记忆；公共话题和规则也可实时编辑。
  “想法摘要”是角色显式生成的短状态报告，模型thinking仍关闭。
  保存版本epoch与实际加载版本loaded_epoch分开显示；只有模型真正使用
  新版指令并返回读群工具调用时，才更新loaded_epoch和loaded_at。
  改单人设定只取消该人尚未发出的旧生成，其他人和现有订单继续运行。
  私人记忆和规则不会通过行情或群消息工具直接传给其他Agent。

存档
  .runtime/state.json 保存聊天、私人状态、市场账户、订单、成交和运行意图。
  页面可导出JSON。技术重启保留市场；明确新建/清空场景会重置市场和聊天。

主要文件
  app.py：API服务、持续Agent循环、实时角色状态与工具。
  market.py：以整数分记账的中央撮合器。
  social_search.py：SocialDataX多平台搜索及结果整理。
  personas.json：8位虚构交易者的初始背景与交易偏好。
  static/：微信式聊天、个人控制台、模拟交易面板。
